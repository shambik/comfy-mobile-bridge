# Commit template

    feat(bootstrap): add portable runtime installer

    Explain the user-visible change, test evidence, installation impact, state
    impact, and rollback. Keep body lines at 100 characters or less.

Use fix(...) for a correction, docs(...) for documentation only, and ci(...)
for workflow changes. A release is created from merged Conventional Commits,
not from a manually edited version in a feature branch.
