# Release checklist

- [ ] CI is green on the final commit.
- [ ] Secret and personal-data scan is clean.
- [ ] npm ci, build, and Python tests pass.
- [ ] Manifests and PowerShell syntax pass.
- [ ] v0.1.0 is based on the clean portable history.
- [ ] GitHub repository is private.
- [ ] Tag and release notes are visible.
- [ ] Installation and rollback commands are documented.
- [ ] Clean-machine acceptance results are reported separately for API, files,
  media, GPU generation, and private network access.
