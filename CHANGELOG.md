## [0.1.0] - 2026-08-13

### Added

- Portable Windows H3 bridge with pinned runtime manifests.
- Resumable model downloads with size and SHA-256 verification.
- Local-only listeners and private Tailscale Serve setup.
- Bootstrap, preflight, doctor, start, stop, update, and rollback commands.
- Agent skills, Git rules, Release Please, and CI checks.
